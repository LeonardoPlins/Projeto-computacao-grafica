# Projeto-computacao-grafica
API de computação gráfica contendo 3 projetos em que o primeiro é relacionado com imagens, o segundo com retas e o terceiro com polígonos 2d.

No primeiro projeto o usuário pode carregar uma imagem e ver o RGB, HSI E CMY ao passar o mouse por ela. além disso ele pode aplicar diversos filtros na imagem.
O segundo projeto tem como objetivo desenhar retas, circunferências e elipses usando diferentes equações e algoritmos para o desenho.
O terceiro projeto possui como ideia central desenhar polígonos 2d em que o usuario pode aplicar diferentes transformações 2d, e preencher o polígono com Flood Fill ou Scanline.
